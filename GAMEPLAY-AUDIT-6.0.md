## Этапы 2–4: разговор, исследование, единый цикл

Используются существующие биографии, правила откровенности, память, свидетели, расписания NPC, поручения и физические свойства; эти системы не заменены декоративными репликами.

- Предлагаемые темы сначала показывают ещё не обсуждённые вопросы. Любознательный общительный NPC может задать встречный бытовой вопрос после еды, напитков, отдыха, увлечений или музыки; действует пауза между инициативами. Ответ о предпочтениях запоминается, отказ отвечать уважается. Само присутствие рядом не открывает разговор.
- Завершённая работа порождает обоснованное признание результата NPC и запись причины изменения доверия в журнале; за одну работу признание учитывается один раз. Существующие конфликты и правила секретности сохраняются.
- Возвращение в обследованное место показывает реальные видимые изменения предметов, людей и проходов. Невидимые предметы и изменения скрытого состояния не становятся «происшествиями». Физические действия и существующие расписания создают новые поводы осмотреться и поговорить.
- Цепочка «цель → работа → ремонт реального предмета → оплата → завершение цели» проверяется в браузере. Также проверены скрытая кража, обнаружение пропажи, изменение подозрения, возврат в изменённую мастерскую и продолжение незавершённого действия после загрузки.

Дополнительно исправлен сервер разработки: он теперь отдаёт все локальные модули интерфейса и `play.html`, а не только четыре первоначальных файла. Файлы вне списка статических ресурсов не обслуживаются.

## Воспроизводимые проверки

```sh
npm run build
npm test
npm run test:gameplay
python3 test/rpg_ui.py
npm run build:pages
```

Браузерные проверки требуют Python Playwright и `/usr/bin/chromium`. Временные отчёты, снимки и сохранения находятся в игнорируемой папке `work/`. `test:gameplay` поднимает собственный сервер на порту 3101 и завершает его после проверки. Основной сервер: `npm start`, порт 3000 по умолчанию.

Результат проверки: **1972/1972 теста прошли**. Браузерные сценарии прошли для исходного приложения и автономной сборки без ошибок JavaScript. Мобильный сценарий прошёл на экранах 390×844, 360×640 и 320×568. Обе сборки созданы успешно.

## Границы результата

Исторические сообщения из старых сохранений не содержат снимков мира. Для них оставлен обычный текст: восстанавливать неизвестную историю по текущему состоянию было бы неверно. Новые сообщения получают снимки автоматически.

Игра остаётся конечной сценарной симуляцией. Неизвестное физическое действие не получает выдуманного успеха; уточнение и варианты продолжения поддерживают замысел в границах существующего мира. Наличие подсказки означает доступный способ взаимодействия, а не гарантированный успех: чужая вещь, запертый объект или разговор могут иметь собственные ограничения.

Критерий «15 минут интересной игры без мыслей о командах» и количественные оценки UX нельзя подтвердить автоматизацией. Для их проверки нужен плейтест с новыми игроками; этот документ не выдаёт автоматическое прохождение за такой эксперимент.
