# Между строк — игра без установки

Откройте **play.html** в современном браузере. Это готовый автономный файл: сервер, Node.js, аккаунт, API, Ollama, модель и интернет не нужны. Файл можно скопировать на другое устройство. На телефоне открытие локального HTML зависит от браузера и файлового менеджера; альтернативно эти же статические файлы можно разместить на обычном веб-хостинге.

## Как играть

Задайте мир, описание персонажа и героя, сохраните вводные. Пишите реплики или действия: «Меня зовут Алекс», «Хочу найти прошлое», «Осматриваюсь», «Беру ключ», «Открываю ларец». Движок запоминает имя и цель, меняет доверие и напряжение, выдаёт предметы и проверяет условия перехода сцены. Встроены четыре набора сцен: фантастика, фэнтези, школа и расследование. Они выбираются по словам в описании мира; доброжелательность и сдержанность в описании персонажа меняют манеру ответа.

Это сценарный движок с распознаванием намерений и шаблонами, не нейросеть и не эквивалент Character AI. Произвольный мир не превращается в полностью новую сюжетную вселенную: используются встроенные сцены. Нераспознанные сообщения получают уточняющий вопрос. История остаётся под контролем игрока.

Сохранение автоматически пишется в браузер. Для локальных файлов браузер может ограничивать localStorage; используйте «Скачать сохранение» и «Загрузить сохранение». Перенос или переименование файла может изменить доступность автоматического сохранения. Смена вводных начинает новый диалог после подтверждения.

## Для разработчика

Исходники: index.html, style.css, engine.js, app.js. Используются обычные скрипты, поддерживающие file://. Никаких зависимостей.

Node.js нужен только разработчику: `npm test` проверяет память, последствия диалога и прохождение сцен; `npm run build` собирает обновлённый play.html. `npm start` — необязательный локальный сервер для разработки. После изменения исходников пересоберите play.html.

## Телефон

Чат занимает один экран; прокручивается только переписка. Кнопка «Настройки» открывает отдельный экран с вводными и сохранениями, «К чату» возвращает к переписке. Высота чата подстраивается под доступную область через Visual Viewport API.

Скачайте актуальный play.html и откройте именно в браузере. Некоторые предпросмотры вложений и файлов на телефоне показывают HTML, но запрещают JavaScript: тогда кнопки не работают, а подсказка «Запуск…» остаётся видна. В таком случае используйте открытие через полноценный браузер или размещение статического файла на веб-хостинге. Установка приложения не требуется.

Проверка мобильного интерфейса для разработчика: `python3 test/mobile.py` (Playwright и системный Chromium). Она использует содержимое автономного файла, проверяет касания, ответы, память и отсутствие прокрутки страницы на пяти размерах. Работа в конкретном мобильном просмотрщике и реальная экранная клавиатура требуют проверки на устройстве.

## GitHub Pages

Публикационная ветка — `gh-pages`, каталог `/ (root)`. В ней размещаются только готовая игра (`index.html`, `play.html`) и `.nojekyll`. Исходники находятся в `main`. Для подготовки новой версии: `npm run build:pages`, `npm test`, затем опубликуйте содержимое `dist/` в `gh-pages`. В Settings → Pages используйте Deploy from a branch → gh-pages → / (root).

На Pages игра открывается сразу в браузере без установки и без серверного приложения. Сохранения привязаны к браузеру и адресу сайта; локальное сохранение из файла можно перенести через экспорт и импорт.
