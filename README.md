# Между строк · версия 4

**[Играть в браузере](https://gdrclm.github.io/Chat/?v=4)** или открыть `play.html` локально. Установки, сервер, API-ключи и загрузка модели игроку не нужны. Готовый HTML содержит всю игру. Сайт требует интернет для загрузки; локальный файл работает без сети.

Версия 4 разделяет истину мира, сообщения игрока и убеждения каждого NPC. Есть реальные предметы, граф мест, память конфликтов, договорённости и отложенные действия. Результат хода виден в чате: успех, частичный успех, отказ или уточнение. Детали показывают распознанное намерение, цель, способ и ожидаемый эффект.

## Игрок и автор

В **настройках автора** задаются мир, герой, персонаж, предметы, правила и карта. В чате слова могут быть ложью: «у меня есть ключ» не создаёт ключ, «запомни: магии нет» не выключает авторскую магию. Для изменения канона используйте настройки. Имя и цель, сообщённые одному NPC, не становятся известны всем.

Кнопка **«Мир»** открывает текущие выходы, собеседников, работу, деньги, причины ссор и ожидающие действия. Можно исследовать город, брать ремонт/доставку, получать оплату и покупать вещи, продолжая жить в том же мире без решения главной загадки.

## Примеры

- «Лгу: монету украл Борис» и позже подброшенная записка могут склонить NPC к ошибочной версии. Для записки нужен предмет-носитель; повтор одной улики не создаёт бесконечных подтверждений.
- «Прошу Миру вынести ларец наружу, спрятать его и открыть позже» предлагает план. Подтвердите «Да», затем доберитесь до предмета и дайте отдельный сигнал открытия. Исполнителю нужен настоящий доступ.
- «Ты идиот», «Прости», затем значимый подарок — разные события. Причина конфликта сохраняется после ухода и возвращения.
- «Превращаю ключ в украшение и дарю его, чтобы заслужить доверие» учитывает материал, происхождение, адресата и результат. Нужна магия либо инструменты. Доверие не открывает замок без отдельной помощи и доступа.
- «Выхожу → Иду в город → Иду в мастерскую → Ищу работу → Да → Работаю → Работаю → Забираю плату» — самостоятельный цикл. По карте можно вернуться в город, дойти до рынка и потратить заработанное.

## Ограничения и сохранение

Это сценарная симуляция с ограниченным русским разбором, не языковая модель Character AI. Убеждения используют простые распознаваемые утверждения и эвристические веса. Сложные стратегии вне обработчиков требуют уточнения. Готовый город, работы и торговля конечны; универсальной генерации любого приключения нет.

Чат занимает один экран; прокручивается переписка. Карта и авторские настройки открываются отдельно. Игра сохраняется в localStorage текущего адреса и браузера. Для копии и переноса доступны экспорт/импорт. Сохранения версии 3 мигрируют. Авторская перестройка сцены сохраняет переписку, но пересоздаёт карту и местные активности; для нормального продолжения используйте сохранение, а не редактирование канона.

Предпросмотры вложений могут блокировать JavaScript. Открывайте сайт либо файл в полноценном браузере.

## Разработка

Node.js 22.8+ нужен только разработчику; сторонних npm-зависимостей нет.

- `npm run build` — пересобрать автономный `play.html`.
- `npm test` — проверки движка, симуляции, миграции и сборки.
- `npm run build:pages` — создать `dist/index.html`, `dist/play.html`, `.nojekyll`.
- `npm start` — необязательный сервер разработки.
- `python3 test/mobile.py`, `python3 test/ui.py`, `python3 test/simulation_ui.py` — браузерные проверки, требующие Playwright и Chromium только в среде разработчика.

`simulation.js` отвечает за мир и NPC; `engine.js` — разбор, обычные действия, реплики и согласование результатов; `app.js` — интерфейс. Обычные скрипты работают без модульной загрузки и сервера. Исходники публикуются в `main`, готовый сайт — в `gh-pages` (`/ (root)`). На Pages Node.js не требуется.
